Theory and revision notes from a 16-week plan to move from Java backend development to LLM application engineering. There is one document per week, written while building the projects.

| Week | Topic | Built in |
| --- | --- | --- |
| 1 | [Python for Java developers](week-01-python-for-java-devs.md) | `rag-docs` (chunking), drills |
| 2 | [Calling LLMs: the Claude API](week-02-claude-api.md) | chat CLI |
| 3 | [Serving LLMs: FastAPI, streaming, Docker](week-03-fastapi-streaming-docker.md) | [chat-service](https://github.com/Vsaraf334/chat-service) |
| 4 | [Embeddings and vector search](week-04-embeddings-vector-search.md) | [rag-docs](https://github.com/Vsaraf334/rag-docs) |

| 6 | [Evaluating RAG: evals and LLM judges](week-06-evals-llm-judge.md) | rag-docs |
| 7 | [Postgres, pgvector and hybrid search](week-07-pgvector-hybrid-search.md) | rag-docs |

## How each document is organised

1. **Concepts:** the theory, explained from first principles, with Java comparisons.
2. **How we built it:** the important code, with explanations.
3. **Key points:** short bullets to skim before an interview.
4. **Gotchas:** real mistakes made along the way, and their fixes.
5. **Revision questions:** with answers at the bottom of the document.
